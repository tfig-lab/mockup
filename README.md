# Cockpit CAPEX · Gestão Integrada da Implantação

Mock-up do painel de gestão do programa de implantação do Modelo de Gestão de CAPEX (pacotes P1 a P9): visão geral, cronograma em tabela e Gantt, curva S por frente e área, cronograma financeiro, evidências, pessoas e riscos.

**Dados ilustrativos.** Nomes, valores e percentuais são fictícios.

## Arquivos

- `index.html` — o cockpit (visual clean), em um arquivo só.
- `classico/index.html` — a versão anterior, com barra lateral azul: `https://tfig-lab.github.io/mockup/classico/`.
- `assets/kpmg-logo.svg` — coloque aqui o logo oficial (versão branca). Sem ele, aparece o texto "KPMG".

## Publicar no GitHub Pages

1. Crie um repositório (ex.: `mockup`) e envie estes arquivos para a branch `main`.
2. Em **Settings → Pages**, escolha **Deploy from a branch**, branch `main`, pasta `/ (root)`, e salve.
3. Em 1 a 2 minutos o site fica em `https://tfig-lab.github.io/mockup/`.

## Observações

- Atividades criadas no Gantt ficam salvas no navegador de quem criou; cada visitante vê só as suas.
- Para testar localmente, basta abrir `index.html` no navegador.
